Hello Again!

Sept 02, 2026 Last Modified: Sept 02, 2026

It’s been quite a while!

I redid the blog, this time with my own custom design which I implemented myself What is implementing yourself in this age of LLM’s? For me and for this blog, it was writing the code mostly myself but occassionally referring to LLM’s for help . Apart from the cosmetic changes, stealing a good idea from other blogs, I have also added a new section called Notes, which is where this post is. The idea is that this would allow me to write about and link to things which might be topical or things that I find interesting, but which are not long form articles. Currently I don’t have a hard-and-fast rule on what is an article and what is not, but I think it would be fairly obvious as I get to writing each of them.

There is a lot left to do with the blog, and I have so many ideas, but I have deliberately paused working on them for now.

One of the main reason for the redesign was that (apart from wanting to try refresh the blog with custom design) I have a lot of things I want to write about. There are already a couple of ideas in my mind and one article that I have kinda already written. My hope is that I will get to all of them soon.
