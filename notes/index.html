I redid the blog, this time with my own custom design which I implemented myself What is implementing yourself in this age of LLM’s? The idea is that this would allow me to write about and link to things which might be topical or things that I find interesting, but which are not long form articles. Currently I don’t have a hard-and-fast rule on what is an article and what is not, but I think it would be fairly obvious as I get to writing each of them.
